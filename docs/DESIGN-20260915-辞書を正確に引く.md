# 辞書を正確に引く ── 比較の語の辞書と、それを引く 1 つの関数（2026-09-15）

Namakoo の線（2026-09-14 夜）: **「辞書登録後は正確に引いてこれる仕組みも必要だ」**。
前日（`DESIGN-20260914-言い回しの到達.md` §3・§8）は盲検で見つけた口語を辞書に足したが、
**引き方**そのものは 08-23 の「最初に当たった語を採る」のままだった。
語を足す前に引き方を測った ── 語を足すほど悪くなる形なら、足すこと自体が害になる。

| ④ | 引けなかった回に**黙って LLM に負ける** | 辞書の外の言い方が増えるほど LLM の不等号が通る |

## §2 形 ── `ailine_core/compare_words.py`

**辞書は表（1 語 1 レコード）**。語だけの tuple をやめた:

```python
Word(text="超え", cmp="gt", guard=NUM_BEFORE,
     source="言い回し 120 件の盲検（2026-09-14）#56「残業時間が20時間超えてる人」",
     since="2026-09-14", example="残業時間が20時間超えてる人")
```

- `source` を必須にした ── **「この語は誰が言ったのか」が機械で辿れる**。頭から思いついた語は
  入らない（訓練常識を昇格させない）。08-23 に「意味から広めた」語はそう書いた（出所を偽らない）
- `example` を必須にした ── 1 語 1 検体。番人が全件回す
- 断片ガードは 3 種だけ（`NONE` / `NUM_BEFORE` / `COUNTER_BEFORE`）＋ 直後の形 `after`
  （「マイナス」の 2 つの意味を後ろで見分ける・09-14 に入れたもの）

**引くのは 1 つの関数** `read(task) -> Reading`:

```
全位置を走査 → ガードを通った一致を集める → 重なる一致は先に始まる方・同じ始まりなら長い方
  否定（直後に ない／ません／なかった／なけれ／ぬ・間に て／てい／ら／では／じゃ を許す）
      → 反転させず**聞き返す**（Reading.ambiguous に文・cmp は None）
  数値の比較が 2 つ（『以上』『未満』）
      → **曖昧**（範囲の抽出はこの道具にない・黙って片方を捨てない）
  数値の比較 ＋ 等しい／含む
      → 数値の側（2 条件の依頼・2 組目は呼び出し側が実表の値で読む 09-06 の道）
  一致なし
      → Reading()（hit=False）── 決めない
```

★ **否定を反転させない**理由: 「超えない＝以下」は定義できるが、黙って反転させるのは
いま直している事故（黙って違うことをする）と同じ形。実測の検体が無い語を機械が決めない。
反転を入れる日は、否定形を**語として**登録する（「超えない」→ lte・出所と検体つき）──
その日のために「同じ始まりなら長い方」を入れてある（§5 の正直な注記を見ること）。

## §3 呼び出し側の規則（3 つの決定点と 4 つの門）

比較を**決める**経路は 3 つ ── EXTRACT（`_verify_extract`）／SET_WHERE／フォルダ抽出
（`cmd_run_folder`）。3 つとも同じ器官を同じ規則で呼ぶ:

1. `Reading.ambiguous` が在れば**断る**（否定・範囲）
2. 引けた比較が LLM と違えば機械が勝つ（開示つき・従来どおり）
3. **辞書に当たらないのに LLM が数値の比較を返した回は実行しない**（`compare_words.unconfirmed`）
   ── 依頼／宣言／実体の三項のうち依頼の側が欠けている。依頼文が無い経路（DSL 直渡し・
   ゴールデン）は触らない。eq は触らない（名指しの抽出の道）
   ★ 置き場所は**境目の接地（threshold.ground）の後ろ** ── 初版は前に置いて「在庫少ないやつ」
   の親切な断り（「多い／少ない」では線を引けない）を横取りし、既存の検体 4 本が捕まえた

比較の**在否**で分岐する門は 4 つ（名指しの抽出／条件つき書換の判定／1 セルの読み直し／
名指しの読み直し）── `compare_words.read(task).hit` を見る。★ `extract_cmp_from_task(task) is None`
では読めない: 否定や範囲は cmp が None でも**比較の依頼**なので、None を「無い」と読むと
「20時間を超えない人」が名指しの門へ流れ、実表に在る `20` を名前として拾う。

`extract_cmp_from_task` は薄い包み（`read(task).cmp`）として残した ── 検体 30 本がこの名前で呼ぶ。

## §4 測定 ── 語彙の共食い（408 句）と、動いた 2 件のうち 1 件を戻した話

09-14 の掃きの句（sonnet 120／haiku 121／Qwen3-8B 167・重複を畳んで 402）を**変える前の
引き方**で読んで保存し、新しい引き方と突き合わせた（純関数なので雑音床 0）:

```
動いた 2 件
  「金額が 50 万以上の取引と以下で背景色を分けてほしい」  gte → 曖昧（『以上』『以下』）  ★ 狙いどおり
  「数量がマイナスなのは全部削除しといて」               None → lt                     ★ 戻した
```

2 件目は俺が「マイナス」の直後の形に「なの」を足した分で、読みとしては正しいが**今日の仕事は
引き方であって辞書の中身ではない**（1 サイクル 1 変更）。戻して、動いたのは狙った 1 件だけにした。
「なの」は候補として残す（発火条件: 実文が 2 件目に出た日）。

この 402 句の読みは `bench/compare_words_freeze.json` に凍結し、番人が「1 件も動かない」を守る。
更新は `AILINE_REGEN_COMPARE_FREEZE=1` で再生成して **git diff を人が読んでから** commit
（公開面の凍結と同じ作法）。凍結の感度は変異で測った（数字の窓を 10→3 にすると赤・§5 ⑧）。

★ 実機テスト（`-m local` 84 本）の依頼文を静的に走査し、規則 3 で断られる文が無いことを確かめた
（数値の比較に見える文はすべて辞書の語を含む。「金額が30000の行」は eq なので対象外）。

## §5 番人と変異

番人（`tests/test_compare_words.py`）:

1. 1 語 1 検体 ── 全レコードの `example` で**その語が**勝つ（到達できない語も同時に捕まる）
2. 出所の無い語は入らない・ガードは 3 種だけ・同じ字面のレコードは 2 つ無い
3. 402 句の読みの凍結（上）
4. 3 つの決定点が同じ器官を呼ぶ（`count_in_product`・旧辞書が本体に残っていない）

変異（各変異を当てて番人を流し、赤を確認して戻す）:

```
① 最長一致をやめる          ★ 初回は緑のまま ── 出荷の辞書には同じ位置から始まる 2 語が無く、
                              規則が発火しようがなかった（在っても鳴らない番人）。検体を**未来の形**
                              （否定形を語として足した辞書）で作り直して赤にした
② 否定を見ない              赤（5 本）
③ 2 つ当たっても片方を採る  赤（3 本・凍結も鳴った）
④ 出所の無い語を足す        赤
⑤ 検体の無い語を足す        赤
⑥ 引けない回に LLM を採る   赤（EXTRACT／SET_WHERE それぞれ）
⑦ 片配線（フォルダ経路だけ旧 API） 赤
⑧ 数字の窓を 10→3          赤（凍結が鳴った＝凍結に感度がある）
```

★ ①の教訓: **規則が在ることと、規則が効く検体が在ることは別**。変異で緑のままなら、規則を
消すか、検体を「その規則が要る日の形」で作るか ── 今回は後者（反転を定義する日が見えている）。

## §6 やらなかったこと・見つけた穴（保留＋発火条件）

- **否定の反転**（「超えない」→ lte）── 聞き返しに留めた。発火条件: 否定形の実文が盲検で出た日に、
  語として登録する（source 必須の表なので、出所なしには入らない）
- **数値でない比較が 2 つ**（「を含む」と「と同じ」）── 旧来どおり先に出た語。発火条件: 実文 1 件
- **`threshold.ZERO_BOUNDARY_WORDS` の「赤字」** ── 掃きの 402 句で「赤字」は 2 件とも**文字を赤に
  する**意味だった（「10個以下の行は赤字にして」）。「赤字＝0 未満」の実文は 0 件。今日は触らないが、
  表に移す日には出所が無いので**入らない**（それが正しい）
- **フォルダ抽出は境目の数を接地していない**（EXTRACT／SET_WHERE は `threshold.ground` を通るが
  `cmd_run_folder` は LLM の value をそのまま float にする）── 兄弟間の片配線の 3 人目。
  今日は比較の規則だけ揃えた。発火条件: フォルダ抽出の盲検を取る日
- **「10を切っていない」は辞書の漏れ**のまま ── 以前は LLM の不等号が黙って通り、いまは規則 3 で
  「比較の語が見つかりません」と止まる。語を足すかは出所（実文）が出てから
