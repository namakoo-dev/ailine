## §2 形 ── `ailine_core/compare_words.py`

**辞書は表（1 語 1 レコード）**。語だけの tuple をやめた:

```python
Word(text="超え", cmp="gt", guard=NUM_BEFORE,
     source="言い回し 120 件の盲検（2026-09-14）#56「残業時間が20時間超えてる人」",
     since="2026-09-14", example="残業時間が20時間超えてる人")
```

- `source` を必須にした ── **「この語は誰が言ったのか」が機械で辿れる**。頭から思いついた語は
  入らない（訓練常識を昇格させない）。08-23 に「意味から広めた」語はそう書いた（出所を偽らない）
- `example` を必須にした ── 1 語 1 検体。番人が全件回す
- 断片ガードは 3 種だけ（`NONE` / `NUM_BEFORE` / `COUNTER_BEFORE`）＋ 直後の形 `after`
  （「マイナス」の 2 つの意味を後ろで見分ける・09-14 に入れたもの）

**引くのは 1 つの関数** `read(task) -> Reading`:

```
全位置を走査 → ガードを通った一致を集める → 重なる一致は先に始まる方・同じ始まりなら長い方
  否定（直後に ない／ません／なかった／なけれ／ぬ・間に て／てい／ら／では／じゃ を許す）
      → 反転させず**聞き返す**（Reading.ambiguous に文・cmp は None）
  数値の比較が 2 つ（『以上』『未満』）
      → **曖昧**（範囲の抽出はこの道具にない・黙って片方を捨てない）
  数値の比較 ＋ 等しい／含む
      → 数値の側（2 条件の依頼・2 組目は呼び出し側が実表の値で読む 09-06 の道）
  一致なし
      → Reading()（hit=False）── 決めない
```

★ **否定を反転させない**理由: 「超えない＝以下」は定義できるが、黙って反転させるのは
いま直している事故（黙って違うことをする）と同じ形。実測の検体が無い語を機械が決めない。
反転を入れる日は、否定形を**語として**登録する（「超えない」→ lte・出所と検体つき）──
その日のために「同じ始まりなら長い方」を入れてある（§5 の正直な注記を見ること）。

## §3 呼び出し側の規則（3 つの決定点と 4 つの門）

比較を**決める**経路は 3 つ ── EXTRACT（`_verify_extract`）／SET_WHERE／フォルダ抽出
（`cmd_run_folder`）。3 つとも同じ器官を同じ規則で呼ぶ:

1. `Reading.ambiguous` が在れば**断る**（否定・範囲）
2. 引けた比較が LLM と違えば機械が勝つ（開示つき・従来どおり）
3. **辞書に当たらないのに LLM が数値の比較を返した回は実行しない**（`compare_words.unconfirmed`）
   ── 依頼／宣言／実体の三項のうち依頼の側が欠けている。依頼文が無い経路（DSL 直渡し・
   ゴールデン）は触らない。eq は触らない（名指しの抽出の道）
   ★ 置き場所は**境目の接地（threshold.ground）の後ろ** ── 初版は前に置いて「在庫少ないやつ」
   の親切な断り（「多い／少ない」では線を引けない）を横取りし、既存の検体 4 本が捕まえた

比較の**在否**で分岐する門は 4 つ（名指しの抽出／条件つき書換の判定／1 セルの読み直し／
名指しの読み直し）── `compare_words.read(task).hit` を見る。★ `extract_cmp_from_task(task) is None`
では読めない: 否定や範囲は cmp が None でも**比較の依頼**なので、None を「無い」と読むと
「20時間を超えない人」が名指しの門へ流れ、実表に在る `20` を名前として拾う。

`extract_cmp_from_task` は薄い包み（`read(task).cmp`）として残した ── 検体 30 本がこの名前で呼ぶ。
