# 請求元と宛先の取り違え ── 2 回失敗して持ち越し（2026-09-18・盲検 4 体目 ②）

★ 状態: **未処置**。2 回当てて 2 回とも正しい冊を巻き添えにしたので、当て推量で 3 回目を
撃たずに止めた（Namakoo 了承）。

## 起きたこと

買い手（記帳代行）の請求書 5 通に `ailine forms` を掛けると:

```
元ファイル             | 請求元 | 宛先               | 請求額(税込)
請求書_大東金属.xlsx   |       | 大東金属 株式会社   | 141900
```

**大東金属は発行元。宛先は顧問先「みどり商事」。**発行元が宛先の欄に入り、請求元は空。
顧問先の名前は一覧のどこにも出ない。全 5 通で `請求元: 無 5`。

★ 買い手:「請求元が全部空・宛先に仕入先名という表は、**そのままでは紙より悪い**
（間違った情報が入っているので）。**この機能は無いのと同じ**です」。
★ 区分は `単`（＝値を出す）で出ている ── README の「空欄は誤値より安い」に反する。
★ `ailine verify` はこれを **✓ で通す**（値が**正しい列に在るか**は見ていない）── ③ として別項。

## 根（読んで確かめた）

```
A3: 大東金属 株式会社   ← 発行元
A5: みどり商事 御中     ← 宛先（法人格の無い屋号）
```

1. `read_addressee` は敬称セル（A5）を見て `clean_org_name("みどり商事 御中")` を呼ぶ
2. `_looks_like_org` は **`_CORP`（株式会社・有限会社…）が含まれるか**だけを見る
   → 「みどり商事」は組織と認められず、名前が 0 行
3. 規則「**敬称のセルは部署か担当者 ── 名前はその上**」が働き、**同じ列の直上（A3）＝発行元**を宛先にする
4. `read_issuer` の①「宛先の名前を含む候補は除く」で、**本物の発行元が消える**

★ **1 つの取り違えが 2 つの欄を壊す。**検分の理由も自白している ──
「A3『大東金属 株式会社』は**宛先と同じ名前です**」（自分が宛先欄に入れた値を根拠にしている）。

★★ `read_issuer` の docstring が**発火条件を予言していた**:
「★ 発火条件: 入れ子の社名を持つ検体が入った時、または**『請求元が空欄になる』報告が来た時**」。
その報告が今日来た。ただし原因は入れ子ではなく**法人格の無い屋号**だった。

## 試して失敗した 2 案（★ どちらも基準線が止めた）

測り方: `bench/received_invoices` の **305 冊**で、触る前の「宛先/請求元が出たか・区分・値」を
凍らせてから差を見る（scratchpad の forms_baseline.py と同型のものを作り直すこと）。
触る前の姿: **宛先が出た 271 / 請求元が出た 254 / 両方 254 / 読めず 0**。

### 案 A: 宛先の側だけ「敬称が付いていれば法人格が無くても名前として採る」
→ **225 冊が動いて悪化**。「総務課 御中」のような**部署名を宛先として採って**しまい、
巻き添えで請求元まで消えた（`宛先: ナギ商会株式会社 → 総務課` / `請求元: 合同会社横手食品 → 無`）。
★ 元の規則（敬称セルが部署なら上を見る）は**正しかった**。

### 案 B: 「上へ辿った名前を宛先にすると請求元の候補が 1 つも残らないなら、辿りを信じない」
→ **16 冊が動いて悪化**。組織名が最初から 1 つしか無い冊（`佐藤 花子 様` の上に宛先の社名）で、
正しい宛先まで落ちた。★ 225 → 16 まで絞れたが、0 ではない。

## 次に当てるなら

見分けの芯はここまで絞れている:

```
T05（正しい）  B4 ナギ商会株式会社（宛先）  B6 佐藤 花子 様   ← 敬称セルは**人名**
俺の冊（壊れる）A3 大東金属 株式会社（発行元）A5 みどり商事 御中 ← 敬称セルは**屋号**
```

**位置では見分けられない**（同じ形をしている）。違うのは「**敬称セル自身が宛先の名前になりうるか**」。
「佐藤 花子」は人名で名前にならず、「みどり商事」はそれ自体が名前。

★ ただしそこを機械で見るのは**語彙の問題**に戻る（人名か／部署名か／屋号か）。
  Namakoo の線:「プリセットとして語彙を入れてもいいかと思ったが、**漏れるリスクも高まる**か」。
  ★ 語彙を入れるなら**主判定にはせず**「当たった時だけ確信を上げる」補助に留めること
    ── 漏れた時に出るのが**誤値**（部署名を宛先として出す）なので代償が高い。
  ★ 棚の線:「語彙は共食いする ── 足すと意味の近い既存から静かに奪う」。

★ もう 1 つの道: **決めずに `割` で出す**（誤値を消し、宛先を空欄にする）。
  「空欄は誤値より安い」に合うが、**いま出ている 271 冊のうち何冊が空欄に落ちるか**を
  先に測ること。測らずに入れない。
