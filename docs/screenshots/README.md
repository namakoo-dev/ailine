# 画面（2026-08-31 実測）

実際に `python gui/server.py` を動かして撮ったものです。加工していません。
モデルは `qwen2.5-coder:7b`（ローカル）、表は `demo/` のサンプルです。

| | 画面 | 何を見るか |
|---|---|---|
| 1 | [書く前に読みを見せる](1_read_before_writing.jpg) | 「こう読みました ── 合っていますか？」。**まだファイルは 1 バイトも変わっていません。** LLM の出力はここで止まり、人が照らす |
| 2 | [`✓` 機械検証済み](2_verified.jpg) | 適用後に開き直して確かめた結果。変わったセルが 1 つずつ挙がり、「**他は 1 セルも変わらず**」まで言う |
| 3 | [`△` 確かめきれていないところがあります](3_partial_with_warning.jpg) | 同じ依頼を**欠けのある表**に出した回。`⚠ 1 行は検証できていません（1 列目が空のため走査がそこで止まり、この行を見ていない）`と名指しして、**`✓` を取り下げる** |
| 4 | [`？` 断り](4_refused.jpg) | 一覧に無い依頼（画像の挿入）。**生成に入らない。**「このまま実行」が押せなくなる |

★ **3 と 4 がこの道具の山場です。** 動くところではなく、`✓` を出さないところを見てください。
