# scripts/ ── 番人と測定器

製品コードではなく、**製品を疑うための道具**を置く。
どれも「在るだけ」では意味が無いので、各項に**実弾で噛むことを確かめたか**を書く。

## 押す前に走る（`scripts/pre-push.sh` が呼ぶ）

| 道具 | 何を見るか | なぜ在るか | 実弾確認 |
|---|---|---|---|
| `lint_product.py` | 製品コード（src/・scripts/）の死んだ変数・未使用 import | 盲検査定で「リンタが CI にも pre-push にも無い」と指摘され、実際に 12 件溜まっていた | ✓ 死んだ変数を足すと exit 1 |
| `ci_parity.py` | **宣言していない依存**を遮断して、CI と同じ素の環境で走らせる | 「手元に在って CI に無いもの」で 4 度落ちた（lxml / ollama / LibreOffice / Pillow） | ✓ Pillow を要求する検体を足すと exit 1 |
| （`pytest -m local`） | 実機 LLM / LibreOffice が要る 14 本 | CI は `-m "not local"` なので、ここで止めないと誰も気づかない | ✓ 検体に変異を入れると exit 1 |

`sh scripts/install-hooks.sh` で clone 直後に入れる（`.git/hooks` は clone で消えるため）。

## 手で走らせる測定器

### `behavior_snapshot.py` ── 修正が**別の所を動かしていないか**
```
python scripts/behavior_snapshot.py --save before   # 直す前
...修正...
python scripts/behavior_snapshot.py --diff before   # 何処が動いたかを全部出す
```
17 場面（help / ops / scan / stack / csv / 異常系…）の画面出力を撮って、一字単位で比べる。

★ **正しさを見ない。何が変わったかだけを見る。** 正しさを知らなくても
「意図していない所が動いた」は分かる。テストが**見ていない**範囲の退行を捕まえるのが役目。
★ LLM を呼ぶ経路は入れない（サンプリングで毎回変わり、差分が意味を失うため）。
★ 実弾確認: 表示文を 1 語変えたら、影響した 2 場面を名指しで出した（exit 1）。

### `fidelity_matrix.py` ── どの経路が Excel の何を保つか
```
python scripts/fidelity_matrix.py
```
飾り 17 種（図形・画像・VBA・結合セル・数式・キャッシュ値・条件付き書式・入力規則・
コメント・リンク・名前定義・フィルタ・印刷範囲・罫線・塗り・数値書式・枠固定）を
仕込んだブックを各経路へ通し、何が残ったかを数えて表にする。

★ 治具の自己検査つき: **仕込めなかった特徴は「消えた」でなく「最初から無い」**ので
表に `-` と出す。初版は 0 しか見ておらず、検体が壊れて全項目 KeyError なのに
「仕込めなかった: []」と報告した。
★ この装置は初回から**製品のバグ**を掴んだ（帳票段が雛形の角印を全枚から消していた）。
