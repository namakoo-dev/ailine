作業フォルダを選び、ファイルを選び、日本語で頼むだけ。

## この画面が**しないこと**

**判定を作りません。** 画面に出る ✓ / △ / ⚠ は、`ailine run --json` が返す
`verdict` を**そのまま映しているだけ**です。

なぜそこまで言うか ── この道具の芯は「確かめられない時に ✓ を出さない」ことで、
その判定を画面が自分で導けば、**同じ判断が 2 つの実装を持つ**ことになります。
2026-08 の盲検で、この repo は「検算の分母が、疑うべき対象と同じ所から作られる」形の
欠陥を 4 回踏みました。画面でそれを新造しないために、機械の番人を置いています
（`tests/test_gui_is_a_thin_shell.py` ── `postcondition` や `advisories` を
画面が読んだ瞬間に赤くなります）。

| verdict | 画面 | 意味 |
|---|---|---|
| `verified` | ✓ | 適用後に読み戻して、宣言どおりに変わったことを確かめた |
| `warned` | △ | 変化は確かめた。ただし ⚠ の分は「宣言どおり」と言えない |
| `unverified` | ⚠ | 読み戻しはしたが、内容は機械で確かめていない |
| `unobservable` | ⚠ | 適用したがファイルを開き直せていない（何も保証しない） |
| `not_applied` | — | 何も主張していない（下書き・断り・失敗） |

## 作りの縛り
- **依存を足さない**（Python 標準ライブラリだけ・番人が確認）
- **localhost にだけ bind する**（外に開かない）
- **この repo の本体を叩く**（`PYTHONPATH` を渡す ── 入れてある古い版を叩かないため）
- **モーダルを使わない**（`alert()` がレンダラを止めて画面が固まった・実測）
