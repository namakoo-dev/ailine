# 実機で走らせた回の証跡（消さない）

ここは作業の残骸ではなく、**製品コードとテストが名指しで参照している実測の記録**です。

## なぜ repo に置いてあるか

この repo は「機械で検証できないものに ✓ を出さない」を掲げています。その裏返しとして、
**「実測した」と書いた箇所には、実測の現物が要る**。ここはその現物です。

製品コード・テスト・文書から、次のファイルが名指しで参照されています:

| 参照元 | 参照先 |
|---|---|
| `src/ailine/__init__.py:1364` | `w3_e2e3_log.txt`（算数が壊れた表示の実測） |
| `tests/test_ailine.py:920` | `w3_e2e3_log.txt`（新規列が見出しとデータ全行に入ることの実測） |
| `bench/realworld/BASELINE.md` | `w3_e2e1_log.txt` / `w3_e2e2_log.txt`（★ 静かに壊れた回の実機ログ） |
| `docs/behavior-corpus/nodes/verification-scope-honesty.md` | `w10e/scenario1_log.txt` |

★ 特に `w3_e2e2_log.txt` は、**見た目は ✓ なのに 1 バイトも変わっていなかった**回
（2 段見出しの表で並べ替えが完全な no-op になった）の実機ログです。
この repo でいちばん重要な失敗の記録なので、消せません。

## 残りのファイル

名指しされていないものは、上記と**同じ実測の回で使った入力ブックとログ**です。
入力（`*.xlsx`）とログ（`*_log.txt`）が対になっており、片方だけ残すと再現できません。

## 触る時の作法

- ★ **中身を書き換えない。** 実測の記録なので、書き換えたら記録ではなくなります
- 新しい実測を足すときは、参照する側（コード・テスト・文書）から**名指しで指す**こと
- 参照されているファイルが消えていないことは `tests/test_e2e_evidence_survives.py` が守ります
