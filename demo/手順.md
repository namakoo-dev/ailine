# 実演の手順（そのまま上から読める形）

★ **動画は撮らない。当日この順で操作する。**
★ 一段ごとに **✓ / △ / ×** のバッジが出る。**バッジが出てから次へ進む**（重ねない）。
★ 「下書きで実行」を押すと、まず **「こう読みました」** が出る。
　**そこではまだファイルは 1 バイトも変わっていない。** 読みを見せてから「このまま実行」。

## 0. 始める前（3 分・前日か当日朝に済ませる）

```powershell
cd C:\Dev\ailine
python gui\server.py
```

ブラウザが `http://127.0.0.1:8760/` を開く。左上のタブが **「1 冊を編集」** になっていること。

★ **前に開いた画面が残っていたら閉じて開き直す**（古い画面には「こう読みました」が無い）。

**必ず先に温めておく**（初回だけモデルの読み込みで 20 秒ほど待つ）:

```powershell
cd C:\Dev\ailine
python -m ailine run demo\2_売上.xlsx "金額で降順に並べ替えて" --dry
```

`解釈: …` の行まで出れば温まっている。`--dry` なのでファイルは変わらない。

**残骸の掃除**（前回の下書きが残っていると関所に止められる）:

```powershell
cd C:\Dev\ailine
Remove-Item demo\*（下書き）*.xlsx, demo\*.out.xlsx -ErrorAction SilentlyContinue
python -m ailine stop
```

## 2. 断る所を見せる（60 秒・ここが商品）

★ **決定的で、毎回同じように出る。** 失敗の展示ではなく「✓ を信じてよい理由」。

### (a) 1 枚に書けないものは書かない

`8月請求` の **5 行目（ヤマノ食品の 2 件目）の担当** を `佐藤` に変える

そのうえで `雛形` の A14 の隣（B14）が `{{担当}}` のまま、もう一度:

```
取引先ごとに請求書を作って

- 期待: **？（断り）**
  `『ヤマノ食品』の [4, 5]行目で『担当』が食い違っています（['田中', '佐藤']）。
   1 枚の紙には 1 つしか書けません ── 明細に出すなら『{{明細:担当}}』にしてください`

> 「**推測で片方を選びません。** 選んだら、間違った担当者の名前が客に届きます」

```

# 困ったときの手当て

| 症状 | 手当て |
|---|---|
| 「こう読みました」が出ない | 古い画面。ブラウザを再読み込み（F5）。それでも出ないならサーバを起動し直す |
| `× 別の ailine が実行中です` | 前の実行が残っている。20 秒待つ → それでも出るなら `python -m ailine stop` |
| `⚠ 出力先に書けません: …out.xlsx` | 前回の残骸。`Remove-Item demo\*.out.xlsx` |
| 15 秒待っても返らない | モデルの読み込み中。**触らずに待つ**（初回だけ 20 秒ほど） |
| 雛形をデータシートと読んだ | 「操作するシート」が `雛形` のままになっている。`8月請求` に戻す |
| 表が更新されない | ブラウザを再読み込み（F5）。下書きは消えない |
| `y/N` を聞かれた | 画面に「承知のうえで続ける／やめる」が出る。**押すのは人** |
| LibreOffice が固まった | `python -m ailine stop` → もう一度実行 |
| 途中でおかしくなった | **「原本からやり直す」** を押す（原本は最初から無変更） |

★ **原本は最後まで変わらない。** 実演中はずっと「下書きで実行」を使う
（`下書きを原本に反映` は押さない）。

# 見せないと決めたもの（聞かれたら答える）

- **会場からもらった自由文を、いきなり実行すること** ── いちばんの地雷。
  頼まれたら**「こう読みました」まで**見せて、実行するかは読みを見てから決める
- **複合依頼**（「◯◯して、そのあと△△して」）── 回ごとに op が変わる実測がある
- **PIVOT** ── DataPilot の再描画で書式が飛ぶ既知の問題
- **その場で雛形を書く** ── IME で全角の `｛｛` を打つと印にならない
- **フォルダ機能・CSV・PDF 書き出し** ── 未処置の既知の問題が残っている
- **29 操作の一覧** ── 数で勝負しない（`ailine ops` でいつでも出せる）
- **生成した Basic** ── 「実行の全文を見る」の中に必ず入っている。求められたら開く

# 質疑で来ると読んでいるもの

| 来る質問 | 答えの芯 |
|---|---|
| 消費税は？ | **道具は税を計算しません**。税率・税額をデータの列で持てば `{{合計:税額}}` で足せます。データに無い判断（8%/10% の区分）は機械には決められないので、やりません |
| インボイス制度の記載事項は？ | 発行者名・登録番号・振込先は**発行者側の定数＝雛形の地の文**です。印のないセルに触らない契約が、そのまま守っています |
| 請求番号の自動採番は？ | **やっていません**。状態を持つと再実行で衝突し、ブック 1 冊から機械検証できなくなる ── この道具の芯の外です。データの列に人が振れば `{{請求番号}}` で今日そのまま出ます |
| 7B でどれだけ正確に翻訳できるの？ | 凍結検体で op 一致 98.1%。**ただし精度は主張の中心ではない** ── 外した時に ✓ を出さない設計だから |
| 言い回しが外れたら？ | 書く前に読みが出ます。違えば操作を選び直せます。**当てにいく設計にしていません** |
| 本番で使える？ | **使えません**。PoC のままです。既知の問題は README に名指しで書いています |
| テストは何を保証してるの？ | 「緑は保証ではありません」。外の目に盲検で測らせて致命 10 件が出ました |
| AI にどこまで書かせた？ | 実装は Claude Code。**判断（何を作らないか）は自分**。採らなかった提案の実例も出せます |
| 12,000 行の 1 ファイルは？ | 割るべきです。**割らなかった理由**は、挙動を変えずに割る番人を用意できていないから |
