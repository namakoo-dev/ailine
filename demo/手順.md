# 実演の手順（そのまま上から読める形）

★ **動画は撮らない。当日この順で操作する。**
★ 一段ごとに **✓ / △ / × / ？** のバッジが出る。**バッジが出てから次へ進む**（重ねない）。
★ 「下書きで実行」を押すと、まず **「こう読みました」** が出る。
　**そこではまだファイルは 1 バイトも変わっていない。** 読みを見せてから「このまま実行」。

## 3. 静かな破壊を捕まえる（3 分）★ ここが他と違う所

### (a) 合計行を巻き込まない

左の一覧から **`4_売上_合計つき.xlsx`**（商品・件数・単価・売上／最下行に合計）:

```
売上の大きい順に並べ替えて
```

- 期待: **✓**。**合計行は最下行のまま**、式も値も無傷
- 解釈行の末尾に `対象から外した行:合計行 6行目（データ行でないため並べ替えません）`

> 「合計行はデータではないので、並べ替えの対象から外しています。
> 外したことは**必ず画面に出します** ── 黙って行を抜かない」

続けて:

```
件数の合計も合計行に入れて
```

- 期待: **✓**、`入れる位置:既にある合計行＝6行目（行は増やしません）`
- 6 行目に件数の合計 **45** が入り、**行は増えない**

### (b) 参照のズレを名指しする ★★ 山場

左の一覧から **`5_参照つき.xlsx`**。**先に中身を見せる**:

| | |
|---|---|
| 5 行目 | `合計 = SUM(B2:B4)` ── 範囲を指す式 |
| 6 行目 | `ぶどうの売上 = B3` ── **特定の 1 行**を指す式 |
| `報告` シート | `一番上の商品の売上 = 売上表!B2` ── **別シート**から |

```
売上の大きい順に並べ替えて
```

- 期待: **△**、そして:

```
⚠ この操作で、指す先の中身が変わる式が 2 件あります:
   報告!B1（=売上表!B2）・売上表!B6（=B3）
   ── 式そのものは壊れませんが、指している行が入れ替わります
```

6 行目を見せる ── ラベルは「ぶどうの売上」なのに、中身は **1,200（りんごの売上）**。

> 「**式は 1 文字も壊れていません。** 壊れたのは意味だけです。
> 値でも文字列でも捕まらないので、**式の中の参照を読んで**見つけています。
> Excel も LibreOffice も、これは仕様どおりの挙動です ── だから**気づけること**が価値です。
> 直すかどうかは人が決めることなので、**直していません**」

★ `=SUM(B2:B4)` には鳴っていないことも見せる ── 範囲は正しく追従するので鳴らさない。

# 見せないと決めたもの（聞かれたら答える）

- **会場からもらった自由文を、いきなり実行すること** ── いちばんの地雷。
  頼まれたら**「こう読みました」まで**見せて、実行するかは読みを見てから決める
- **複合依頼**（「◯◯して、そのあと△△して」）── 回ごとに op が変わる実測がある
- **PIVOT** ── DataPilot の再描画で書式が飛ぶ既知の問題
- **その場で雛形を書く** ── IME で全角の `｛｛` を打つと印にならない
- **フォルダ機能・CSV・PDF 書き出し** ── 未処置の既知の問題が残っている
- **29 操作の一覧** ── 数で勝負しない（`ailine ops` でいつでも出せる）

# 質疑で来ると読んでいるもの

| 来る質問 | 答えの芯 |
|---|---|
| 消費税は？ | **道具は税を計算しません**。税率・税額をデータの列で持てば `{{合計:税額}}` で足せます。データに無い判断（8%/10% の区分）は機械には決められないので、やりません |
| インボイス制度の記載事項は？ | 発行者名・登録番号・振込先は**発行者側の定数＝雛形の地の文**です。印のないセルに触らない契約が、そのまま守っています |
| 請求番号の自動採番は？ | **やっていません**。状態を持つと再実行で衝突し、ブック 1 冊から機械検証できなくなる ── この道具の芯の外です |
| 参照のズレは直せないの？ | **直せます**。付け替えた式の**計算値が操作前と同じ**かで検算もできます。ただし「行に追従したい」のか「アドレスに留めたい」のかは**人の意図**なので、確認を取ってからにします |
| 言い回しが外れたら？ | 書く前に読みが出ます。違えば選び直せます。**当てにいく設計にしていません** |
| 本番で使える？ | **使えません**。PoC のままです。既知の問題は README に名指しで書いています |
| テストは何を保証してるの？ | 「緑は保証ではありません」。実際、この 2 日で発注者が手で触って**18 件**見つけました ── 全部、試験が緑のまま素通りしていたものです |
| AI にどこまで書かせた？ | 実装は Claude Code。**判断（何を作らないか）は自分**。採らなかった提案の実例も出せます |
| 12,000 行の 1 ファイルは？ | 割るべきです。**割らなかった理由**は、挙動を変えずに割る番人を用意できていないから |
