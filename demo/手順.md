## 0. 始める前（3 分・前日か当日朝に済ませる）

```powershell
cd C:\Dev\ailine
python gui\server.py
```

ブラウザが `http://127.0.0.1:8760/` を開く。左上のタブが **「1 冊を編集」** になっていること。

**必ず先に温めておく**（初回だけモデルの読み込みで 20 秒ほど待つ）:

```powershell
cd C:\Dev\ailine
python -m ailine run demo\2_売上.xlsx "金額で降順に並べ替えて" --dry
```

`解釈: …` の行まで出れば温まっている。`--dry` なのでファイルは変わらない。

**残骸の掃除**（前回の下書きが残っていると関所に止められる）:

```powershell
cd C:\Dev\ailine
Remove-Item demo\*（下書き）*.xlsx, demo\*.out.xlsx -ErrorAction SilentlyContinue
python -m ailine stop
```

## 1. 本編（約 2 分半）

### ① ファイルを選ぶ

左の一覧から **`1_請求_2026年8月.xlsx`** をクリック。

- 右に **8月請求** の表が出る（取引先・件数・単価・金額・締め日・担当／5 社）
- 画面の一番上に「いま触っている: 1_請求_2026年8月.xlsx シート 8月請求」と出る

> 言うこと:「毎月これを見て、5 社ぶんの請求書を手で作っています」

### ② 合計を出す

`② 日本語で頼む` に入れて **「下書きで実行」**:

```
金額の合計を出して
```

- 期待: **✓ 機械検証済み**
- 見せる所: `事後条件を確認（操作:合計追加）: 7行目の合計を検証（5 行分・式・キャッシュ値・ラベルとも一致）`

### ③ 列を足す（位置を言葉で指す）

```
担当の右に確認という列を追加して
```

- 期待: **✓**
- 見せる所: 解釈行の `入れる位置:『担当』（6列目）の右＝7列目`

> 言うこと:「位置は AI が数えたのではなく、**機械が見出しを読んで決めています**」

### ④ 条件つきで印を付ける

```
金額が100000以上の行の確認列に「★」を付けて
```

- 期待: **✓**
- 見せる所（**実行する前**に出る）:
  `条件:『金額』が 100000 以上　当てはまる行:1 行（5行目）　対象から外した行:合計行 7行目（データ行でないため）`

> 言うこと:「**押す前に**どの行が対象か出ます。合計行は請求の行ではないので外しています」

### ⑤ ★ 山場 ── 請求書を作る

```
取引先ごとに請求書を作って
```

- 期待: **✓**（15〜25 秒かかる。待つ）
- 見せる所: `データ5行 → 出力5枚（印7箇所/枚）（印の値・型とも保存・雛形/データシート無変更）`

> 言うこと:「**雛形は人が作ります。機械は印（`{{列名}}`）のあるセルだけ埋めて、
> それ以外は 1 セルも触りません**」

### ⑥ 出来たものを見せる

画面上の **「操作するシート」** で `北斗精機` を選ぶ。

- 罫線・網掛け・`114,000 円` の書式がそのまま残っている
- 「備考」欄（印が無いセル）は雛形のまま

見た目まで見せたいときは **「Excel/LibreOffice で開く」** を押す（本物のアプリで開く）。

### ⑦ 検分シート

「操作するシート」で **`検分`** を選ぶ。

| シート名 | 元の行 | 埋めた印の数 |
|---|---|---|
| 丸和物流 | 2 | 7 |
| …（5 行） | | |

> 言うこと:「**どのシートを・どの行から・印を何個埋めたか**を、道具が自分で出します」

### ⑧ ✓ の意味を 1 行で

> 「いまの ✓ は、**書いたあとファイルを開き直して数え直した**結果です。
> だから**この表は見直さなくていい**。ここが提供している価値です」

# 困ったときの手当て

| 症状 | 手当て |
|---|---|
| `× 別の ailine が実行中です` | 前の実行が残っている。20 秒待つ → それでも出るなら `python -m ailine stop` |
| `⚠ 出力先に書けません: …out.xlsx` | 前回の残骸。`Remove-Item demo\*.out.xlsx` |
| 15 秒待っても返らない | モデルの読み込み中。**触らずに待つ**（初回だけ 20 秒ほど） |
| 表が更新されない | ブラウザを再読み込み（F5）。下書きは消えない |
| `y/N` を聞かれた | 画面に「承知のうえで続ける／やめる」が出る。**押すのは人** |
| LibreOffice が固まった | `python -m ailine stop` → もう一度実行 |
| 途中でおかしくなった | **「原本からやり直す」** を押す（原本は最初から無変更） |

★ **原本は最後まで変わらない。** 実演中はずっと「下書きで実行」を使う
（`下書きを原本に反映` は押さない）。
