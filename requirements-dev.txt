# ★ lxml は敢えて入れない（2026-08-15 の判断）。
# openpyxl は lxml があればそちらで XML を書き、無ければ ElementTree に落ちる。
# 空の <v> が <v></v> と <v /> に分かれるため、開発機（lxml あり）で緑でも
# CI（lxml なし）で 12 本落ちるという実害が出た。
# 直し方は 2 通りあったが、
#   (a) lxml を固定して CI を開発機に合わせる → 差が消えるのではなく見えなくなる
#   (b) テスト側を両方の直列化に耐えさせる    → 採用
# を採った。CI が lxml 無しで走り続けることで、素の環境が常に被覆される。
